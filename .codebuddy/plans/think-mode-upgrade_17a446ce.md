## 产品概述

为拍照成诗小程序升级智谱生成流程，启用深度思考模式（think_mode），复用用户已选素材生成，并在生成过程中展示“深度思考中/Think 模式”状态提示。

## 核心功能

- 请求参数增加 think_mode（或等效官方参数）开启深度思考
- 生成流程复用已选照片/文案等素材进行创作
- 生成时在 UI 显示“深度思考中/Think 模式”状态文案与加载提示
- 保持原有模型与输出链路，其余逻辑不变

## 技术选型与架构

- 保持现有小程序前端框架与项目结构，最小侵入式改造
- 前端：更新生成流程的状态管理，增加 Think 状态提示
- 后端/云函数：请求参数加入 think_mode: true（或官方等效），确保复用素材入参不变
- 交互链路：生成流程状态分为待生成/深度思考中/生成完成；错误时提示重试

采用现代感玻璃拟态风格，突出“深度思考”状态：顶部保持品牌区，中部为素材预览与状态提示区，底部操作区含生成/重试按钮。Think 状态采用发光渐变进度提示与柔和动效，保证在加载时清晰展示。

## Agent Extensions

### SubAgent

- **code-explorer**
- Purpose: 全局检索生成流程与 API 调用处，定位参数与状态 UI 位置
- Expected outcome: 找到需修改的文件路径与具体代码位置
