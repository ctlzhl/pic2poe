## Product Overview

优化小程序首页上传体验，去除“开始创作”按钮自身loading，仅保留上传流程的全局蒙层加载提示，避免重复叠加。

## Core Features

- 首页“开始创作”按钮不再显示loading样式
- 上传提交时仅显示全局蒙层加载提示
- 确保蒙层状态与上传流程同步，避免遮挡或遗漏
- 回归检查：按钮可重复点击防抖，蒙层关闭后按钮状态恢复正常

## 技术方案

- 架构：小程序前端单体架构，页面逻辑与组件解耦
- 前端：原有小程序技术栈，保持现有状态管理与事件流
- 状态管理：按钮不再绑定loading状态；全局蒙层由上传流程状态统一控制
- 接口联动：上传开始/成功/失败统一触发蒙层显示/隐藏，按钮仅做防抖与禁用
- 关键改动：移除按钮loading绑定；保留并校准全局蒙层触发点与关闭时机

## 设计思路

保持现有首页布局与品牌样式，移除按钮loading动画，上传时仅出现半透明全局蒙层与中心进度提示，确保视觉层级清晰，避免重复加载反馈。
