## Product Overview

全项目静态审计工具，扫描微信小程序与云函数代码、资源、测试与文档文件，生成未引用候选清单并标记报告，不执行删除。

## Core Features

- 依赖与入口配置解析：识别小程序页面、组件、云函数与配置入口
- 代码与资源引用追踪：构建依赖图，标记未被引用的 JS/TS/WXML/WXSS/资源文件
- 测试与文档覆盖检查：检测测试、文档文件的引用与孤立状态
- 报告与标记输出：输出详细候选清单（含路径、类型、理由），支持机器可读与可视摘要

## 技术栈与架构

- 形态：本地/CI 可运行的 Node.js CLI 工具
- 核心框架：Node.js + TypeScript，命令行交互与文件系统分析
- 依赖解析：AST/静态分析，支持 WXML/WXSS/JS/TS/JSON 配置解析
- 报告输出：JSON + Markdown 双格式，包含统计摘要与详细项
- 架构：分层模块（输入配置层、解析层、引用追踪层、规则评估层、报告层），可扩展规则插件

## Agent Extensions

### SubAgent

- **code-explorer**
- Purpose: 跨多文件/目录搜索与分析项目结构，收集入口与依赖
- Expected outcome: 获得全局文件分布与依赖线索，为未引用判定提供依据
