# P1：云端配置与验收

本说明只针对新版“照片有话说”P1。不要修改或复用旧版 `poemRecords`、`generatePoem`。

## 1. 创建新版集合并收紧权限

在云开发控制台的“数据库”中，逐一新建下列集合：

```text
users
imageAssets
creationDrafts
creationTasks
creationAttempts
works
shareCards
```

每个集合的权限都选择“仅云函数/管理员可读写”（界面文字因开发者工具版本可能略有不同）。目标是：小程序客户端不能直接读取或写入这些集合；所有数据都必须经过云函数中 `OPENID` 归属校验。

建议创建以下业务索引：

| 集合 | 索引字段 | 用途 |
| --- | --- | --- |
| `imageAssets` | `expiresAt` 升序 | 定时清理过期资产 |
| `creationTasks` | `userId` 升序、`idempotencyKey` 升序 | 防止重复提交 |
| `creationTasks` | `userId` 升序、`status` 升序 | 拒绝同一用户的并行任务 |
| `creationTasks` | `status` 升序、`deadlineAt` 升序 | 回收超时任务 |
| `works` | `userId` 升序、`createdAt` 降序 | 我的作品列表 |
| `shareCards` | `workId` 升序、`userId` 升序、`contentHash` 升序、`status` 升序、`templateVersion` 升序 | 复用同一作品的分享成品图 |
| `shareCards` | `shareToken` 升序、`status` 升序 | 按分享凭证读取公开作品快照 |
| `shareCards` | `status` 升序 | 回收已撤销分享图 |

### Sharp 云函数的部署前置条件

`prepareImage` 与 `createShareCard` 使用 Sharp，且配置为不在云端重新安装依赖。每次在**新的电脑、干净工作目录或更新 Sharp 后**部署前，都要在下列两个目录分别执行一次（不要把 `node_modules` 提交到 Git）：

```bash
cd cloudfunctions/prepareImage
npm install --include=optional --os=linux --cpu=x64 --libc=glibc

cd ../createShareCard
npm install --include=optional --os=linux --cpu=x64 --libc=glibc

cd ../..
```

随后再执行上方对应函数的部署命令。这样打包进云函数的是 Linux x64 的 Sharp 二进制，避免本机 macOS 依赖被上传后在 Node.js 20 云端无法加载。

如果此前尚未部署全部 P1 函数，则依次部署：

```bash
tcb fn deploy createImageUpload -r ap-shanghai
tcb fn deploy prepareImage -r ap-shanghai
tcb fn deploy createCreation -r ap-shanghai
tcb fn deploy runCreation -r ap-shanghai
tcb fn deploy getCreation -r ap-shanghai
tcb fn deploy getWork -r ap-shanghai
tcb fn deploy listWorks -r ap-shanghai
tcb fn deploy deleteWork -r ap-shanghai
tcb fn deploy retryCreation -r ap-shanghai

tcb fn deploy cleanupExpiredAssets -r ap-shanghai
tcb fn deploy createShareCard -r ap-shanghai

```

部署后确认 `runCreation`、`recoverStuckTasks` 与 `cleanupExpiredAssets` 的“触发器”中分别出现每分钟、每分钟与每 15 分钟任务。

## 3. 小程序验收

1. 微信开发者工具重新编译小程序，确认环境初始化为 `cloud1-8gefec0p0d1f809d`。
2. 选择一张不超过 6MB 的 JPG、PNG 或 WebP；页面应显示“图片已准备好”。
3. 选择“五言绝句 / 图评 / 文案”任一类型，点击“开始生成”。
4. 在“正在创作”页停留 10 秒，应只出现一次“正在努力创作中”。未配置模型环境变量时，任务会安全失败并提示创作服务尚未准备好；配置完成后才会进入真实模型调用。
5. 点击“再试一次”，`attemptNumber` 应增加，且不用再次上传图片。
6. 分别测试超过 6MB 的文件、HEIC 和伪装成图片的损坏文件，均不应创建可创作资产。

## 4. P1 完成边界

P1 已包含上传、任务、超时和重试；内容生成与类型化结果依赖下列 P2 环境变量。不要把任何 API Key 写入小程序或 Git：

```text
DASHSCOPE_API_KEY
DASHSCOPE_BASE_URL
QWEN_VISION_MODEL
ZHIPU_API_KEY
GLM_BASE_URL
GLM_TEXT_MODEL
MODEL_PROMPT_VERSION
MODEL_REQUEST_TIMEOUT_MS
MODEL_MAX_RETRIES
VISION_TEMPERATURE
GENERATION_TEMPERATURE
VISION_MAX_TOKENS
GENERATION_MAX_TOKENS
```

后七项均在 `runCreation` 云函数环境变量中配置；未设置时会采用代码中的保守默认值。建议生产环境显式填写并记录变更，例如 `MODEL_REQUEST_TIMEOUT_MS=18000`、`MODEL_MAX_RETRIES=1`。

## 5. P3 分享配置与验收

`shareCards` 也必须配置为“仅云函数/管理员可读写”。公开访问不直接读取数据库，而是只通过 `getSharedWork` 校验不可猜测的分享凭证后返回公开作品快照；不要把 `works` 或 `imageAssets` 改成公开读。

分享图使用云调用生成带参小程序码。`createShareCard/config.json` 已声明 `wxacode.getUnlimited` 的 OpenAPI 调用权限；该文件必须随函数一起部署，否则云端会返回 `-604101`。联调阶段可不配置 `WXACODE_ENV_VERSION`，默认生成开发版小程序码；提交正式版前，在 `runCreation` 之外的 `createShareCard` 环境变量中设置：

```text
WXACODE_ENV_VERSION=release
```

若环境的云调用权限仍返回 `-604101`，函数会自动回退到微信服务端小程序码接口。此时在 **createShareCard** 的云函数环境变量中仅配置以下两项（不要写入代码、`cloudbaserc.json` 或数据库）：

```text
WECHAT_MINIPROGRAM_APP_ID=你的小程序AppID
WECHAT_MINIPROGRAM_APP_SECRET=你的小程序AppSecret
```

验收：打开一份已完成作品，等待分享成品图出现；可保存到相册、通过“发给好友”转发，并在第二个微信账号打开后看到只读作品。朋友圈分享请在真机右上角菜单验证；开发者工具不提供完整的朋友圈分享验证。

## 6. P4 上线前加固

- 新创作限制为每位用户 10 分钟 4 次、24 小时 20 次；同一任务最多生成 3 次。数值在 `createCreation` 与 `retryCreation` 中实施，避免模型调用被滥用。
- `works`、`imageAssets`、`creationDrafts`、`creationTasks`、`creationAttempts`、`shareCards` 均保持“仅云函数/管理员可读写”。小程序仅能经云函数读取自己的作品；公开分享仅能经不可猜测的 `shareToken` 读取快照。
- 删除作品会先撤销关联分享凭证，再删除关联的任务、草稿、图片和分享图；存储删除短暂失败时由现有定时清理函数在后续轮次回收，已撤销的分享链接不再可打开。
- 上线正式版前，在 **createShareCard** 的环境变量中设置 `WXACODE_ENV_VERSION=release`。保留 `WECHAT_MINIPROGRAM_APP_ID` 与 `WECHAT_MINIPROGRAM_APP_SECRET` 仅在云函数环境变量中，绝不写入代码、数据库或版本库。
- 真机验收须覆盖：JPG/PNG/WebP、HEIC 的友好提示、失败任务重试、作品删除、好友分享和扫码进入。开发者工具不等同于朋友圈和扫码的最终行为。
- 在云存储中为 `original/` 配置生命周期规则：对象创建 **2 天后删除**。这是 24 小时应用清理任务的兜底；创建后上传一张测试图片，并在控制台确认规则已命中该前缀。
